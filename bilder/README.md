# Bilder-Ordner

Hier alle Bilder (und das Startseiten-Video) ablegen. Jede Bildfläche der Website lädt automatisch die Datei mit dem passenden Namen.

## So geht's

1. Bild genau so benennen wie in der Tabelle unten, z. B. `mowo-2.jpg`.
2. Erlaubte Endungen: `.jpg`, `.jpeg`, `.png`, `.webp` (Name ohne Endung muss stimmen, Kleinschreibung).
3. Datei in diesen Ordner `bilder/` hochladen (auf GitHub: *Add file → Upload files*).
4. Fertig – solange ein Bild fehlt, zeigt die Website an der Stelle eine graue Fläche mit dem erwarteten Dateinamen.

**Tipp:** Bilder vorher verkleinern (ca. 1600–2000 px Breite, < 500 KB), damit die Seite schnell lädt. Das Video sollte als MP4 (H.264) ohne Ton und möglichst unter 10 MB sein – GitHub erlaubt maximal 100 MB pro Datei.
