# Icons

Alle Icons der Website liegen hier als SVG-Datei. Die Seiten binden sie per Link ein
(`<img src="icons/…svg">`). Um ein Icon zu ändern, einfach die Datei mit **gleichem Namen** ersetzen.

sonst verschiebt sich das Layout.
